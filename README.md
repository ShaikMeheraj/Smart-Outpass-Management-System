# Smart Outpass Management System

## Project Overview

The Smart Outpass Management System is a web-based application designed to automate hostel outpass management using facial recognition technology. The system helps educational institutions monitor student movement efficiently while reducing manual paperwork and unauthorized exits.

## Key Features

- Student Registration
- Secure Login Authentication
- Outpass Request Submission
- Admin Approval Workflow
- Facial Recognition Verification
- Student Exit Monitoring
- Database Management
- Real-Time Status Tracking

## Technologies Used

- Python
- Streamlit
- SQLite
- OpenCV
- CNN (Convolutional Neural Network)
- Haar Cascade Classifier

## System Modules

### Student Module
- Registration
- Login
- Apply for Outpass
- Track Request Status

### Administrator Module
- Review Requests
- Approve/Reject Outpasses
- Monitor Student Records

### Security Module
- Face Verification
- Exit Validation
- Unauthorized Access Prevention

## Project Benefits

- Reduces manual paperwork
- Improves hostel security
- Prevents unauthorized exits
- Automates approval process
- Maintains centralized records

## Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/Smart-Outpass-Management-System.git
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run main.py
```
